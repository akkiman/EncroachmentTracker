How we report.

A complaint is stronger when it is calm, accurate and easy to check.

Describe, do not accuse.

We write what the photo shows, with words like "appears to". We never write about the owner.

Public ground only.

Photos are taken from the road or the footpath. Nobody enters private property.

No faces, no number plates.

Admins review every photo and can blur or reject it before it is used.

Observations, not verdicts.

Only PMC decides what is an encroachment, and only the FDA decides if a food stall breaks the rules. We make it easy to tell them clearly.

Help keep one road clear.

Ask for access with your name and email. An admin approves you and you can start the same day.

Questions.

Who can use it?

Approved members of the project. Request access and an admin will review it. Logging in uses a code sent to your email, so there is no password to remember.

Is this an official PMC service?

No. It is a citizens' tool. Letters are addressed to PMC or the FDA and you send them yourself. Whether something is an encroachment is for PMC to decide.

Does it cover food safety?

In a limited way. For street food stalls, members can report visible licence and hygiene points, such as no FSSAI number on display or food kept uncovered. The letter goes to the Maharashtra FDA, which decides what to do. We report conditions, never people. The aim is a safe, legal stall, not one fewer vendor.

Do I need a PMC portal account?

No. The portal helper is optional. If you have an account, it copies the details you need and tracks the complaint number for you.

What happens to my photos?

They are stored in a private Google Drive folder and are visible only to approved members. When you add a photo, it is also sent to an AI service to suggest a description. You can ask an admin to remove a photo at any time.

Does it cost anything?

It is free for members. A project admin pays for the AI and hosting, which is why each member has a daily limit on photo analysis.
